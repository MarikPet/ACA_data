# Working with GitHub

## Steps

1. Create a repo in GitHub
2. Copy the link of the repo
3. Open the Terminal
4. Type `git clone https://github.com/username/myrepo.git`,click *Enter* ```(*Do this after each step in Terminal*)```
5. Type `code .` to open VSCode
6. Open the repo folder
7. Create a file in the folder
8. In Terminal write `git add <your_new_file_name>`
9. Type `git commit -m "a meaningful message"`
10. Type `git push`
11. Go to your GitHub account on browser and see your file added to the remote repo
